# مستندات المنصة المصدرية

ما في هذا المجلد يُنشر مع الشيفرة عمداً، لأن قرص الخدمة على الخطة المجانية
مؤقّت: كل نشر جديد يمسح ما رُفع من الواجهة. فالملف الذي يجب أن يبقى متاحاً
للطلاب بعد كل نشر يُحفظ هنا ويُدخَل إلى التخزين أثناء البناء.

## الملفات

| الملف | الوصف |
|---|---|
| `StudentGuide2026.pdf` | دليل الطالب 2026 الصادر عن مركز القبول الموحد. 273 صفحة. |

## كيف يصل الملف إلى المنصة

```bash
npm run guide:import content/StudentGuide2026.pdf "دليل الطالب 2026"
```

السكربت آمن عند التكرار: يوازن بصمة الملف بما هو منشور، فإن كانت النسخة
نفسها لم يفعل شيئاً. لذلك يُستدعى في أمر البناء على Render بلا خوف من
تكرار النسخ أو إنشاء إصدارات فارغة.

## بنك أسئلة جويب

بنك الأسئلة المستخرج من هذا الدليل يُبنى بأمر منفصل، ومخرجاته نصّية تُحفظ في
`prisma/seed-data/faq-guide.json` وتُدخَل بـ `npm run faq:guide`. إعادة بنائه
تحتاج `pdftotext` وصفحات الدليل النصّية:

```bash
pdftotext -enc UTF-8 content/StudentGuide2026.pdf all.txt
# ثم قسّم all.txt على محرف الصفحة \f إلى pages/p001.txt ...
npm run faq:build -- <مجلد-الصفحات>
```

## التحقّق من دليل التخصصات

بعد أي تحديث للدليل، تُطابَق بيانات البرامج بصفحاته:

```bash
pdftotext -enc UTF-8 content/StudentGuide2026.pdf all.txt
# قسّم all.txt على محرف الصفحة  إلى pages/p001.txt ...
npm run programs:verify -- <مجلد-الصفحات>
```

يخرج برمز خطأ إن وُجد برنامج في غير صفحته، أو مجال لا يطابق نطاقه، أو برنامج
في الدليل وليس في المنصة.

## ملفات المكتبة

المكتبة فهرس عناوين، وملفات الكتب ليست هنا ولا في المستودع. حتى يُرفع الملف
تعرض صفحة العنوان أنه «مُدرَج في الفهرس» وتدعو الطالب لسؤال المختص.

طريقان لإرفاق النسخ:

1. من لوحة المختص، عنواناً عنواناً.
2. دفعةً واحدة، بوضع الملفات في مجلد وتسمية كل ملف باسم الكتاب:

```bash
npm run library:files -- <مجلد-الملفات>          # عرض ما سيحدث
npm run library:files -- <مجلد-الملفات> --apply  # التنفيذ
```

السكربت يوازن اسم الملف بعناوين المكتبة ولا يرفق إلا ما تجاوز تشابهه 60%،
ويعرض ما لم يجد له تطابقاً مؤكّداً لتراجعه بنفسك. PDF يُرفق نسخةً للقراءة،
و MP3 نسخةً مسموعة.

حقوق النشر مسؤولية من يرفع: لا تُرفع نسخة كتاب إلا إذا كان حقّ إتاحتها
للطلاب مملوكاً أو مأذوناً به.
