```bash
npm test          # 50 اختباراً
```

ولا تمسّ أي بيانات أخرى.

## تنبيه بناء معروف

`npm run build` يُظهر تنبيهاً واحداً من أداة تتبّع الملفات في Turbopack سببه أن جذر التخزين
يُقرأ من البيئة وقت التشغيل (`resolve(process.cwd(), STORAGE_DIR)`). التنبيه يخصّ حجم حزمة
النشر لا صحّة التشغيل، وهو مقصود لأن موقع التخزين يتغيّر بين بيئة وأخرى.
